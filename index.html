// REPO-03 · AUTONOMOUS-ENGINEERING-SYSTEMBun · Tauri · MCP stdio · MIT

        

          

            
Three agents. Six gates.

            
autonomousengineeringsystem — the closed loop. Orion drafts the PRD, Daedalus locks the ADR, Vulcan plans the work, the executor writes the code — and Aegis, six compiler-grounded gates, refuses every commit until it's green. Gate fails? The loop heals itself and ships anyway. No context dumping: AST receipts, zero token waste.
